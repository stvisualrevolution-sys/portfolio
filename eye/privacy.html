眼科動画ルーチン（eye-video-routine）

制定・最終更新：2026年10月10日

このツールについて

眼科動画ルーチンは、眼科の一般的な説明動画の制作と、運営者自身の YouTube チャンネルへの投稿を支援する、運営者専用のデスクトップツールです。一般の閲覧者に Google アカウントの接続を求めるサービスではありません。患者さん個人の診療情報を取り扱う目的では使用しません。

アクセスする情報と利用目的

  • Google の認証画面で許可を得たうえで、YouTube API からチャンネルの識別番号と名前を取得し、投稿先が正しいことを確認します。
  • 運営者が用意した動画、タイトル、説明文、サムネイルおよび公開設定を YouTube に送信して投稿します。
  • 投稿した動画の識別番号、URL、公開設定、投稿日時や処理結果を記録し、重複投稿の防止や処理状況の確認に使用します。
  • 継続して投稿するために、Google が発行する認証情報を保存します。Google アカウントのパスワードをこのツールが取得・保存することはありません。

要求する権限は、動画のアップロードに使用する youtube.upload と、投稿先の確認に使用する youtube.readonly です。Google の許可画面に表示される権限の範囲でアクセスします。

保存場所と管理

認証情報と投稿記録は、運営者が管理する Mac のローカルファイルに保存します。認証情報のファイルは、保存した利用者だけが読み書きできる権限で管理します。認証情報をこの公開サイトや公開リポジトリに掲載しません。接続を継続する間は認証情報を保持し、投稿記録は運営上必要な間保持します。

外部への送信と公開

認証と投稿のために必要な情報を Google・YouTube に送信します。動画等は、運営者が指定した公開範囲に従い YouTube 上で公開または保存されます。YouTube API から取得したデータを販売したり、広告配信のために利用したり、汎用 AI モデルの学習に使用したりすることはありません。認証情報を動画制作に使う生成 AI に渡すことはありません。

Google API から受け取った情報の使用および他のアプリへの転送は、制限付き使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

接続の解除とデータの削除

運営者は Google アカウントの接続管理画面 で、このアプリへのアクセス許可をいつでも取り消せます。利用を終了するときは、Mac に保存した認証情報と、不要になった投稿記録も削除します。接続の解除だけでは投稿済みの動画は削除されません。動画の削除や公開範囲の変更は YouTube Studio で行います。

この説明サイトについて

本ページとホームページは GitHub Pages で公開しています。アクセス時には、配信に必要な IP アドレスなどをホスティング事業者が取り扱う場合があります。詳しくは GitHub のプライバシーに関する声明 をご覧ください。このツールの認証情報を本サイトで収集することはありません。
